## Side findings from the prebuild

- **Meta Layout SDK links into every flavor.** Generated `app/build.gradle:193-195` declares the metavrx BOM and both artifacts as plain `implementation`, so the pico and mobile APKs also carry `MANAGE_APP_VOLUMETRIC_WINDOWS` and the Horizon SDK declarations (Harlem ADR 0001). Harlem's fix is `@expo-pico/core` `metaLayoutSdk: true` (writes `questImplementation`) plus Viro `metaSpatialLayout: false`. The installed `@expo-pico/core` (`release/core` @ `6307e39`) has no `metaLayoutSdk` option, so this needs a dependency bump first. Not done here.
- **`SYSTEM_ALERT_WINDOW` is in the questDebug manifest** (merged line 13). The quest flavor removes it, but the debug build-type manifest ranks above the flavor in the merge. Release is not affected; the existing verifier only checks the flavor file.

# M15 Rest: accessibility

WCAG 2.2 AA; ratios measured 2026-10-08.

## Contrast (night scheme)

| Pair | Fg | Bg | Ratio | Need | Result |
|---|---|---|---:|---|---|
| Status, cost line | #F8F8F8 | scrim #0A1230 | 17.31 | 4.5 | pass |
| Caption | `silver` #BEC0C2 | #0A1230 | 10.08 | 4.5 | pass |
| Ring fill vs track | carolina #4BA8F0 | `border` #1A2E6E | 4.92 | 3 | pass |
| Wake button edge | `silver` | `night` #00041C | 11.13 | 3 | pass |
| Focus | carolina | `night` | 7.89 | 3 | pass |

The dimmed scene never sits behind text without the scrim.

## Focus order

Status line → Energy ring → cost line (when shown) → Wake button → shell keys → trackpad.

## Hold alternative (2.5.1, 2.2.1)

Trackpad hold is 600 ms. VoiceOver/TalkBack expose `commit` as a named action (`m15.trackpad.commit`). The on-screen Wake button needs no hold; on the early path it reveals the confirm row, so there is still a deliberate second step without timing.

## Announcements

`m15.sleeping` once on entering sleeping. `m15.woke.*` once. Ring value changes are not announced while sleeping.

## Reduced motion

Scheme change instant; static sleeping and awake poses; hold progress replaced by the button path (the trackpad hold still works, ring flashes white instead of filling, per `Trackpad` reduced feedback).

## Dynamic Type

Status and cost lines wrap to four lines at XXL on SE; the Mon scales down to keep them on screen. Button labels up to 24 characters; long names wrap inside the button.

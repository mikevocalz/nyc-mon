# M12 3D hatch evidence

Captured 2026-10-21 on branch `feat/egg-native-hatch`.

- `threejs-playback.webp`: each egg's GLB loaded by three.js 0.186.1 `GLTFLoader`
  in headless Chromium (WebGL2), seeked to the start of `stir`, crack beats 1
  and 3, mid-burst, the start and end of `emerge`, and the end of
  `attention_hesitate`. Produced by `tooling/blender/hatching/playback/`.
  The white figure is the labeled `PROXY_*` Baby; in the app it is hidden and
  the creature layer draws the Baby.
- `source-six-views.webp`: the creator's four egg meshes as supplied, front,
  back, left, right, top and bottom (rows: Corner, Prism, Signal, Metro).

Not shown here: anything on a phone, WebGPU frame times, or the real Baby
models, which don't exist yet.

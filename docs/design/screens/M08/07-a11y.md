# M08 Meeting: accessibility

Owner: `a11y-auditor`. Standard: WCAG 2.1 AA as the floor, with the WCAG 2.2 target-size and pointer rules the repo already applies (https://www.w3.org/TR/WCAG22/), Apple HIG and Android accessibility, and the W3C XR Accessibility User Requirements for the Quest 2D window (https://www.w3.org/TR/xaur/). Inputs: `03-direction.md`, `04-components.md`, `05-copy.md`, `docs/design/hlynk/DIRECTION.md`, `docs/DESIGN_SYSTEM.md`.

**Verdict:** accessible once `ChoiceTriptych` ships with radio semantics and the card scrolls at large text. The highest risks are a gesture-only commit (covered by `TrackpadActions` and the confirm step) and the focus ring on night pages.

## Focus order

Browsing:

1. Status row (consent pending item, only when present)
2. `m08.title` (`Heading level={1}`), initial focus
3. `m08.santoro.caption`
4. Tile group (`radiogroup`, label `m08.title`): one Tab stop, the roving tile (`rovingTabIndex`); none checked, so tile 1 takes the stop
5. `TrackpadActions`: Look closer
6. Shell: Home, Menu, Trackpad, Back, Forward (the shell's own order, M01 handoff)

Approaching: focus moves to the card's heading (the egg name, `titleLevel={2}`), then number, Bloodline, body, Previous egg, All three, Next egg, Choose. Confirming: focus moves to `m08.confirm.title`, then Choose this egg, Keep looking. Leaving confirm returns focus to the Choose button it came from. Leaving approaching ("All three") returns focus to the tile that was open.

## Reduced motion map

| Motion | Full | Reduced |
|---|---|---|
| Tile → full screen | 300 ms scale from tile frame | 200 ms cross-fade |
| Egg wobble | two ±3° rotations, 600 ms, once per focus | none |
| Card rise | 300 ms, 8 pt rise | 200 ms fade |
| Step to next egg | 200 ms, 24 pt slide | 120 ms cross-fade |
| Hold progress (trackpad ring fills over 600 ms) | ring fill | ring fill kept: it is progress feedback, not decoration; no scale |
| Chosen | ring flash 120 ms, `motion-step` | colour change, cut |

Reduced motion is read once at the sim-core adapter and passed as `reducedMotion` (§3.6). Nothing flashes more than 3 times a second (2.3.1).

## Dynamic Type

| Size | Behaviour |
|---|---|
| Default | layout as `03-direction.md` |
| XXL | tile labels wrap to two lines; card text scales; the card scrolls inside the 3:4 screen with the Choose button pinned to its bottom edge |
| Accessibility sizes | triptych becomes a vertical list of three rows (still image 64 pt + name + Bloodline); the radio semantics stay; approaching becomes a full-screen scroll view |

## Touch targets

| Control | Size | Result |
|---|---|---|
| Tile | about 103 × 129 pt on SE | pass |
| `TrackpadActions` buttons (`size="sm"`) | must measure ≥ 44 pt tall; the non-ghost kit `sm` is `py-2.5` plus a `text-sm` line, about 40 pt, with no `min-h` (`Button.tsx:68`); only the ghost look carries `min-h-11` | **fix**: request `size="md"` here, or the kit raises `sm` to 44 pt hit area |
| Choose, confirm pair | `lg`, ≥ 48 pt | pass |
| Trackpad, keys | 112 pt, 48 pt | pass |

## Keyboard (web and Quest 2D window)

| Element | Tab | Enter / Space | Escape | Arrows |
|---|---|---|---|---|
| Tile group | one stop | open the focused egg | — | move between tiles (`nextRadioIndex`), Home/End |
| Card | in order | activate the focused button | back to all three | Left/Right step eggs |
| Confirm | in order | activate | Keep looking | — |

Quest 2D window: controller ray and hand pinch map to tap; hold-to-commit maps to a 600 ms pinch hold. XAUR "input" needs: every action is reachable by pointer select alone through `TrackpadActions`.

## Findings

| # | Issue | WCAG | Severity | Fix |
|---|---|---|---|---|
| 1 | A hold-only commit would block switch and voice users | 2.5.1, 2.1.1 | Blocker if shipped alone | `TrackpadActions` Choose + confirm; VoiceOver commit action |
| 2 | `royal-500` focus ring on night is 3.63:1 | 1.4.11, 2.4.7 | Medium | `royal-300` on night (8.92) |
| 3 | `TrackpadActions` `sm` buttons may fall under 44 pt | 2.5.5 | Medium | larger size or hit slop |
| 4 | Image alt read twice (tile label + image) in browsing | 1.1.1 noise | Low | hide the image from AT in browsing |
| 5 | Card overflow at XXL | 1.4.4, 1.4.10 | Medium | card scrolls; list layout at accessibility sizes |

# G02 Game lobby: accessibility

Owner: `a11y-auditor`. Standard: WCAG 2.2 AA (https://www.w3.org/TR/WCAG22/), Apple HIG accessibility (https://developer.apple.com/design/human-interface-guidelines/accessibility), Android accessibility (https://developer.android.com/guide/topics/ui/accessibility), Rive semantics (https://rive.app/docs/editor/accessibility/semantics). Inputs: `03-direction.md` to `06-critique.md`, `docs/DESIGN_SYSTEM.md`, `docs/design/CONTRAST.md`, `docs/COPY_DECK.md`. Stage: design. Nothing is built; every row is a requirement, not a result.

**Verdict:** likely accessible foundation. Two risks carry into the handoff: the Rive artboards must expose a real semantics tree (the runtime supports it; nothing here proves the authored file does), and the uppercase START legend at XXL Dynamic Type.

## Focus order

1. Wordmark (`image`, heading level 1, "NYC-Mon").
2. NYC Rank panel: a `region` named `g02.rank.a11y.region`. Inside: the status line (if not `ready`), then rows in rank order, then the own row, then "Try again" when present.
3. Resume block: `Heading level={2}` ("Continue your game" or "Start a new game"), then the district line as plain text.
4. Strip (resume failure or offline), when present, with its action.
5. START.

START is last in reading order and first in importance. On screen-reader open, focus lands on the wordmark and the screen title `g02.screen.a11y` is announced. No "jump to Start" magic action: five stops is short, and skipping would lose the resume line that says what START does.

## Reduced motion map

Gated once by the sim-core adapter (`AccessibilityInfo.isReduceMotionEnabled` native, `prefers-reduced-motion` web), passed as `reducedMotion` to `GameLobby` and bound to Rive `a11y/reducedMotion` (§8). Components never read the OS themselves.

| Motion | Full | Reduced (authored sibling) |
|---|---|---|
| Lobby enter (`motion-enter`) | 300 ms fade + 8 pt rise, staggered 60 ms | 200 ms fade, no rise, no stagger |
| START energy trace | one perimeter run on enter, ≤ 1.2 s, then still | absent; steady 2 dp rim (`carolina-500` night, `royal-500` day) |
| START press (`motion-tap`) | 120 ms, scale 0.97 + Rive compression | colour to `cta-pressed`, 120 ms |
| START → gameplay | Rive loading transition, held until resume is ready | 200 ms cross-fade, same gate |
| Rank row reorder (`motion-step`) | 200 ms slide | 120 ms cross-fade |
| Panel status change | 200 ms cross-fade | instant |
| Panel entrance (Rive) | segmented header lights left to right, 300 ms | header drawn lit |

Copy does not change in either mode. **Flash safety (2.3.1):** the energy trace is one pass of a 2 dp line, no blink; the header lighting is one rise. Nothing on this screen flashes. **2.3.3:** every interaction animation has the reduced column above.

## Dynamic Type

- Resume title (`type-title` 24 pt) and body scale with the OS up to XXL. At XXL "Continue your game" wraps to two lines on SE (343 pt); the block reserves two lines so START does not move.
- START legend: `type-tag` 14 pt scales to about 21 pt at XXL; the button grows in height, never clips. Uppercase tracked text at large sizes is harder for dyslexic readers; the accessible name is sentence case, and `design-director` may swap the legend to `type-label` "Start" (Decision in `03-direction.md`). Finding 2.
- Rank rows: the name truncates at one line (`LongName` story); the accessible label carries the full name.
- Large Content Viewer (iOS): START sets `accessibilityShowsLargeContentViewer` with its accessible name.

| 1 | Rive artboards may ship without a semantics tree, leaving the panel and START as one opaque image | 4.1.2 Name, Role, Value | High | Author Rive semantics on the panel, every row, and START; the CLI `--semantics` run is a PR artifact (§8); the native wrapper mirrors the tree if the runtime cannot expose it |

# M06 Notifications permission: accessibility

Owner: `a11y-auditor`. Standard: WCAG 2.2 AA (https://www.w3.org/TR/WCAG22/), WAI-ARIA dialog (modal) pattern (https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/), Apple HIG and Android accessibility. Inputs: `03-direction.md`, `04-components.md`, `05-copy.md`, `06-critique.md`, `docs/design/DECISIONS.md` P2, `docs/DESIGN_SYSTEM.md`, `docs/COPY_DECK.md`, kit source (`packages/ui/BottomSheet.tsx`).

**Verdict:** likely accessible foundation. It is a short modal with two equal actions and no time pressure. Two kit facts need handling: `SheetSurface` forces the night scheme and hardcodes its close label in English.

## Contrast

Method: `contrastRatio()` from `packages/theme/contrast.ts`, 2026-10-04, hexes from `docs/DESIGN_SYSTEM.md` (theme agent's in-flight `tokens.ts` matched at measurement time).

`SheetSurface` today renders inside `NIGHT_SCHEME` whatever the OS says. Under D8 a non-chrome screen follows the OS appearance, so this audit measures both and the handoff asks the kit for a `scheme` prop. Night is measured first because it is what the kit renders today.

## Focus order

The sheet is modal. While it is open, M10 behind it is hidden from assistive tech (`accessibilityViewIsModal` on iOS, `importantForAccessibility="no-hide-descendants"` on the background on Android, `aria-modal="true"` + inert background on web).

1. Title `m06.title`, `Heading level={2}` (initial focus)
2. Notification preview (one image element)
3. Body `m06.body.15` / `.30` / `.60`
4. Turn on notifications
5. Not now
6. Grabber / close (`m06.grabber.a11y.label`), last, because Not now already does the same thing

The preview sits between title and body in reading order because the body ("That's in about 30 minutes") refers to it.

After the sheet closes (any path), focus moves to M11's `h1`. When the OS prompt appears, the OS owns focus; when it returns, focus goes to M11 too, never back into a sheet that has closed.

## Dynamic Type

| Size | Behaviour |
|---|---|
| Default (SE, medium detent) | title two lines, preview, body two lines, two buttons: fits |
| XXL | the sheet opens at the large detent; content scrolls inside the sheet; buttons stay pinned to the sheet bottom |
| Accessibility sizes | the preview card keeps its height but its text wraps; nothing truncates, unlike a real lock-screen banner (the preview is an illustration of meaning, not a pixel copy) |

Rules for this screen:

- One status line at a time, a sentence with no exclamation mark. Calls name the want ("Asking for food"); the false call says only "Calling for you", because telling a real call from a false one is the Caller's part.
- Canon language: Caller, never owner or player; H-Lynk, never "device"; no pronoun for the Mon (PS-005), so lines repeat `{name}`.
- Banned: sick, dead, died, killed, neglected, punish. A cold is "a cold". Mistakes are never written anywhere.
- Discipline is "Set a boundary". A boundary is something friends set with each other, so the word keeps the Caller and the Mon equals (Decision #8; v11 lets Mons disagree and refuse). "Discipline", "scold" and "punish" frame the Caller as in control and are not used.
- Weight is a number with no judgement ("Weight 6"). No band words (D20f).
- Character lines: a Mon line ships only where canon gives one. Mike's Hood Ratti line rules (2026-10-23, Q32) give a Squeaklet "Food?" and "Bet!"; nothing else is written for a Baby, and the other Bloodlines' slots are `TODO(canon)` and ship empty.
- Reduced motion never changes copy.

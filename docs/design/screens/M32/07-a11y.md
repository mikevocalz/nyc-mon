# M32 Mon Space: accessibility

Standard: WCAG 2.2 AA (https://www.w3.org/TR/WCAG22/), Apple HIG, Android accessibility. Contrast ratios for the LCD paper, ink, lit-ink and backlight tokens are measured by lane (d) when the tokens land (`packages/theme/contrast.ts`, Law 10); until then no ratio here is claimed. Targets: LCD text runs 4.5:1 cell ink against cell ground (not against grid lines); hearts, glyphs and the lamp 3:1 as UI graphics (1.4.11). Text strokes are at least two LCD cells thick, or bypass the grid.

## No state carried by sound or colour alone

| State | Visual | Text / spoken | Sound | Haptic |
|---|---|---|---|---|
| Real call | Lamp blink + call glyph | Status line, announced politely once | `attention` | `warning`-class attention preset |
| False call | Same lamp and glyph | "Calling for you" | `attention` | same |
| Hearts | Filled vs outline glyphs (shape, not colour) | "Fullness, 3 of 4 hearts" | none | none |
| Poop | Pile glyphs, one per pile | "{count} piles to clean" | none | none |
| Cold | Cold glyph on the Mon | "{name} has a cold" | none | none |
| Lights out | Inverted LCD | "Lights out. {name} is asleep." | none | none |
| Paused | Dark lamp, "Paused" line, disabled icons | "Paused" + each icon's reason | none | none |
| Action landed | Sprite reaction | Result line announced | action cue | `success` |

Sound is never the only channel; with sound off (`soundEnabled()` false) or the silent switch on, every row above still reads.

## VoiceOver labels (every LCD element)

The LCD is one texture, so every element has a real accessible twin in reading order. Labels use `docs/COPY_DECK.md` keys.

| Element | Role | Label | Value / hint |
|---|---|---|---|
| Back | button | `monspace.back` | `monspace.back.hint` |
| Attention lamp | text, live region polite | `monspace.a11y.lamp.call` / `.false_call` / `.off` | announced on change only |
| Mon | image | `monspace.a11y.mon` | the current pose word |
| Each heart row | progressbar (0–4) | `monspace.hearts.fullness` / `.energy` / `.social` | `monspace.a11y.hearts` ("3 of 4 hearts") |
| Poop piles | text | `monspace.status.poop.*` | — |
| Cold glyph | text | `monspace.status.cold` | — |
| Call glyph | text | the status line | — |
| Status line | text, live region polite | current `monspace.call.*` or `monspace.status.*` | — |
| Each icon (9) | button | `monspace.menu.*` | `monspace.menu.*.hint`; disabled reason as the value |
| A / B / C keys | button | `monspace.key.next` / `.select` / `.back` | hints say what happens |
| Boundaries segments | progressbar (0–4) | `monspace.status.boundaries` | "{level} of 4" |
| Weight, age (segment numerals) | text | `monspace.status.weight`, `monspace.status.age` | the number as words |

Focus order: Back, lamp/status line, Mon, heart rows, poop and cold, icon bar left to right, A/B/C keys. Focus starts on the status line when a call is open.

## Reduce Motion (authored, not derived)

- LCD ghosting persistence 0; no bloom pulse; no step-in/step-out tween (cross-fade 120 ms instead).
- Lamp: steady with the exclamation dot (`motion-led-blink-needs-you` reduced step).
- Idle: one pose change per vignette slot as a cross-fade.
- Lights out and evolve: instant invert or none; the evolve name fades in.
- Flush: piles disappear.
- Copy never changes.

## Reduce Transparency

Bloom off. Night keeps the backlight and the inverted palette.

## Flashing

Every lamp rhythm stays at or under 3 flashes in any one-second window (WCAG 2.3.1), checked by `maxFlashesPerSecond`. No full-screen flash, including evolve and lights-out.

## Input

- Every action reachable by direct tap, by A/B/C, by hardware keyboard (arrows, Return/Space, Escape) and by Switch Control.
- Targets 56 pt for A/B/C, 44 pt minimum for icons.
- Swipe on the LCD cycles icons; it always has the A key as its equivalent (2.5.1).

## Dynamic Type

The LCD texture cannot scale. The status line and the status page's accessible twins are real text and scale; at XXL the status page shows a `KeyValueList` beside or under the LCD. Tablets show the twins in the `CompanionPane`.

# M09 Naming ceremony: accessibility

Owner: `a11y-auditor`. Standard: WCAG 2.1 AA floor plus the repo's WCAG 2.2 rules; W3C XAUR for the Quest 2D window. Inputs: `03-direction.md`, `04-components.md`, `05-copy.md`, `screens/M07/07-a11y.md` (shared field, plate and error patterns).

**Verdict:** accessible once the scrim is in place, the plate stays silent, and the compact-shell switch keeps focus where it was. The pattern is M07's, so most findings are inherited fixes.

## Focus order

Arrival from M12 (keyboard down):

1. `m09.title` (`Heading level={1}`), initial focus. M12's last announcement must finish first; M09 does not announce on arrival.
2. `m09.identity`
3. Baby image (`CREATURE_ART` alt)
4. Name field (`m09.field.label`, hint `m09.field.hint`)
5. Clear (when text)
6. Error (when present)
7. Plate (when text)
8. Use this name
9. Shell: Home (disabled), Menu, Trackpad, Back (disabled), Forward (disabled)

No native autofocus (M07 finding 5): the keyboard would cover the Baby the moment it hatched, and VoiceOver would skip the title. When the keyboard opens and the shell goes compact, focus stays on the field; nothing in the switch moves it.

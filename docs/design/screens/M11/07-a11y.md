# M11 Incubating: accessibility

Owner: `a11y-auditor`. Standard: WCAG 2.2 AA (https://www.w3.org/TR/WCAG22/), Apple HIG, Android accessibility, W3C XR Accessibility User Requirements (https://www.w3.org/TR/xaur/) for the Quest 2D window. Inputs: `03-direction.md`, `04-components.md`, `05-copy.md`, `docs/design/hlynk/DIRECTION.md`.

**Verdict:** accessible once the warm has its non-haptic equivalents and the ring stays decorative. No timing requirement is placed on the Caller anywhere on this screen.

## Focus order (VoiceOver / TalkBack)

1. Status light: "Status light: Incubating, 12 minutes left" (`hlynk.led.a11y`)
2. Case image: `m11.case.a11y.label`
3. Time line: "12 minutes left" then "Metro Egg, ready at 4:12 PM" (one element; the ring is hidden)
4. Status row items, if notifications are off: `m11.status.notify_off`, then its action
5. Trackpad: label `m11.trackpad.warm` / `m11.trackpad.open`, hint from copy
6. `TrackpadActions` button with the same label (the labelled equivalent)
7. Keys: Home (disabled here: this is home), Menu, Back, Forward (disabled: nothing to step)

## Screen reader behaviour

- The time text is **not** a live region. Counting down in a live region would announce every minute. VoiceOver reads the current value when focused.
- One polite announcement on the ready edge (`m11.a11y.announce.ready`) and none on later visits.
- Warm: trackpad `accessibilityActions` `activate` runs one breath (pad glow + one `haptics.warm` + `m11.a11y.announce.warm`). No hold is required (WCAG 2.5.1, 2.5.7).

## Reduced motion map

| Element | Full | Reduced |
|---|---|---|
| LED | breath 4 s / ready blink | steady + tick row / steady + filled dot |
| Ring | continuous | one step per minute |
| Pad glow | breathes with the LED | steady while held |
| Ready seam | 300 ms rise | instant |

Reduced motion is read once by the sim-core adapter and passed in as `reducedMotion` (§3.6). No component reads `AccessibilityInfo` itself.

## Haptics are never the only channel

The warm is a haptic, a visual (pad glow) and, for screen-reader users, a spoken line. The pad glow is the primary channel on devices with no haptic engine, with haptics off in M19, and in the Quest 2D window (XAUR: redundant output modalities).

## Dynamic Type

Text plate grows upward; at XXL the time line wraps to two lines and the ring drops to 48 pt. At AX sizes the egg name moves under the time line. The case scales down to keep the plate inside the screen; the plate never covers the pad.

## Flash safety

Ready blink is 2 blinks per 6 s (`maxFlashesPerSecond` ≤ 3, enforced by `hlynk.test.ts`). Pad glow is a slow breath, not a flash.

## Quest 2D window (1280 × 800 dp)

Controller ray and hand pinch drive the trackpad as a pointer; pinch-and-hold = hold. Hover shows the kit focus ring on the trackpad and keys. Targets keep their 48 pt size; at Quest panel distance that meets Meta's recommended minimum (verify on device). No haptic reaches the controllers from the phone haptic API.

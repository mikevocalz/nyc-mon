# M10 Incubation choice: accessibility

Owner: `a11y-auditor`. Standard: WCAG 2.1 AA floor plus the repo's WCAG 2.2 pointer and target rules; W3C XAUR for the Quest 2D window. Inputs: `03-direction.md`, `04-components.md`, `05-copy.md`, `docs/design/hlynk/DIRECTION.md`.

**Verdict:** accessible once `IncubationRing` exposes its stops as real radios (not canvas hit-tests) and the case animation has its cross-fade sibling. The Skia ring must never be the only way to pick a time.

## Focus order

1. Status row item (consent pending only)
2. `m10.title`, initial focus
3. `m10.body`
4. Ring group (`radiogroup`, `m10.ring.a11y.label`): one Tab stop; none checked, so 15 takes the stop
5. Egg image (`m10.egg.a11y.label`)
6. Ready-at line (when present)
7. Start incubating
8. `TrackpadActions` (Shorter, Longer)
9. Shell controls

After confirm: polite `m10.confirmed.a11y.announce`; if the M06 sheet opens, it takes focus (M06 07-a11y); otherwise M11's `h1` does.

## Reduced motion map

| Motion | Full | Reduced |
|---|---|---|
| Arc fill on select | 200 ms along the arc | instant |
| Ready-at appears | `motion-enter` | 200 ms fade |
| Case closes | 700 ms hinge | 200 ms cross-fade to closed |
| LED | `motion-led-breath` | steady + tick row |
| Hold before sheet | 400 ms | after the cross-fade |

## Dynamic Type

| Size | Behaviour |
|---|---|
| Default | ring 260 pt max |
| XXL | ring shrinks to keep labels outside the arcs; title wraps to three lines; the screen scrolls, Start pinned |
| Accessibility sizes | the ring becomes three full-width radio rows ("15 minutes", "30 minutes", "1 hour") with the egg above; the ring returns at M11 as display only |

## Findings

| # | Issue | WCAG | Severity | Fix |
|---|---|---|---|---|
| 1 | Skia-only stops would be invisible to AT | 4.1.2, 2.1.1 | Blocker | RN radios over the canvas |
| 2 | Pale unselected arcs (concrete-300, 1.75:1) | 1.4.11 | High | concrete-500 |
| 3 | A live-updating Ready-at would chatter | 4.1.3 noise | Medium | not a live region |
| 4 | Case vanishes on night page | legibility | Low | concrete-400 edge |
| 5 | A countdown here invites watching and adds a timing cue some players read as pressure | 2.2.1 spirit | Low | countdown lives on M11 only |

## Focus order

Back → heading → days-together count → previous month → month grid (arrow keys move by day on web/Quest; swipe on native moves cell to cell) → next month → timeline (day heading, then items).

## Screen reader

- Grid announces "Days together, October 2026". Each cell: "October 5, together" or "October 6". Missed and future days are read the same way.
- Selecting a day moves focus to that day's heading in the timeline.
- Firsts read "{name}'s first meal, First".

## Reduced motion

Month change cross-fades; no dot pop-in.

## Dynamic Type

Calendar cells grow to 48 pt and the grid scrolls horizontally inside its card only if seven cells no longer fit (SE at XXL: 7 × 44 = 308 pt in a 343 pt column, fits). Timeline items wrap freely.

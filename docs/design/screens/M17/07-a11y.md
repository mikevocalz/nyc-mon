## Focus order

Back → Photo (if present) → portrait (image, label "{name}, {formName}") → Dex number → form name → bloodline → Life stages group → Name → Hatched → Caller.

Photo mode: Cancel → pose strip (if any) → shutter. Export done: Share → Done. Focus moves to Share when the export finishes and the toast is announced.

## Labels

- `SignagePlate` keeps the full text in `accessibilityLabel`; the Dex plate reads `m17.dex.a11y`.
- `LifecycleTrack`: one group; done and current slots read their form name and state; all `later` slots read once as `m17.life.later.a11y`, not three times.
- `KeyValueList` rows read "Hatched, 4 October 2026" (label, value).

## Reduced motion

Entry fade only; photo-mode expand becomes a cross-fade; no shutter flash.

## Dynamic Type

Signage plate steps down from `station` to `title`, then wraps (its own contract). Fact rows stack label above value at XXL. Two-column layout on expanded drops to one column when the text size makes the right column narrower than 320 pt.

# G03 Game-control settings: accessibility

Owner: `a11y-auditor`. Standard: WCAG 2.2 AA (https://www.w3.org/TR/WCAG22/), Apple HIG accessibility (https://developer.apple.com/design/human-interface-guidelines/accessibility), Android accessibility (https://developer.android.com/guide/topics/ui/accessibility), Xbox Accessibility Guidelines (https://learn.microsoft.com/en-us/gaming/accessibility/guidelines) for remapping and input. Inputs: `03-direction.md`, `04-components.md`, `05-copy.md`, `06-critique.md`, `docs/design/CONTRAST.md`, `G01-arcade-controller/07-a11y.md` (the preview's pairs). Stage: design. Nothing is built, so every row below is a requirement, not a test result.

**Verdict:** likely accessible foundation. Two kit gaps (spoken slider units, a non-drag path in the placement editor) and one long image label carry into the handoff.

## Dragging movements (SC 2.5.7)

`ClusterPlacementEditor` offers, for each handle: pointer drag; four nudge buttons (8 dp per press); keyboard arrows while the handle has focus (web and hardware keyboards); and "Reset position". Every path ends in the same `ControllerLayoutResolver.validate` call. The caption `g03.placement.caption` names the non-drag path. Pass by design; verify with Switch Control on device.

## Grouping and labels (SC 1.3.1, 3.3.2)

- Web: each `FieldGroup.Section` renders a `<fieldset>` with a `<legend>` through `@acme/ui/html` (`Fieldset`, `Legend`); the four section titles are the legends.
- Native: sections are `accessibilityRole="header"` titles; each `SegmentedControl` carries its own `aria-label` from `05-copy.md` (`g03.stick.mode.a11y` and so on) because the visible label ("Mode") needs the section to disambiguate.
- Every `Slider` has `label`; every `Switch` has `label`. No icon-only control exists on this page except the nudge buttons, which carry `g03.placement.nudge.*`.

## Name, role, value (SC 4.1.2)

| Element | Role | Name | Value / state |
|---|---|---|---|
| `Slider` | `adjustable` (native) / `slider` (web) | the `label` prop | `accessibilityValue.text` from `valueText` (NEW prop): "15 percent", "1 times". Without it VoiceOver reads the raw number: finding 1 |
| `SegmentedControl` | radio group | `aria-label` | selected option announced |
| `Switch` | switch | label | on / off |
| `ControllerPreview` | image | `g03.preview.a11y`, rebuilt on every change | none; inner controls hidden (`accessibilityElementsHidden`, `importantForAccessibility="no-hide-descendants"`) |
| Placement handle | `adjustable` | `g03.placement.*.handle` | position as "x, y points from the corner"; increment/decrement map to nudge |
| `StatusRow` lines | text, `output` live region on web | label | polite |
| Restore dialog | dialog, focus trapped, Escape closes | `g03.restore.title` | — |

## Focus order

1. Back control (navigation chrome) → 2. Title "Game controls" → 3. `ControllerPreview` (one element) → 4. reduced-motion `StatusRow` and its "Change" action (if shown) → 5. clamp notice (if shown) → 6. Stick: Mode, Placement, Dead zone, Sensitivity → 7. Layout: Hand, Size, Opacity, Position handles and nudges (tablet, book, web) → 8. Feel: Haptics, Show icons → 9. Buttons: the KeyValueList (not focusable; read in sequence) → 10. Restore defaults.

After "Restore" in the dialog, focus returns to the Restore button and `g03.restore.done` is announced politely. After an invalid placement, focus stays on the handle and `g03.placement.invalid` is announced.

## Reduced motion map

Gated once by the sim-core adapter (`useReducedMotion`), passed down as `reducedMotion`. Components never read the OS themselves.

| Motion | Full | Reduced (authored sibling) |
|---|---|---|
| Slider / segment change | `motion-tap` scale 0.97 | colour change only, 120 ms |
| Restore defaults | controls slide to defaults, `motion-step` 200 ms | 120 ms cross-fade |
| Handedness mirror in the preview | `motion-step` slide | cross-fade |
| Preview controller | G01's full idle, press and held variants | G01's authored reduced siblings (steady rims, press as colour change) |
| Placement snap-back | 200 ms slide to the last valid spot | instant |

Copy does not change in either mode. The `StatusRow` `g03.reduced.on` appears only when the OS reports reduced motion.

## Flash safety (SC 2.3.1)

Nothing on this page blinks. The preview inherits G01's limits (no more than three flashes per second; the pill's confirmation pulse is one rise).

## Dynamic Type

Labels, captions and values scale with Dynamic Type up to XXL. Segments wrap to a 2×2 grid when a row would exceed the pane width; slider value labels sit above the track at XXL instead of beside it. The preview well does not scale with type; its accessibility label carries the values.

## Findings

| # | Issue | WCAG | Severity | Fix |
|---|---|---|---|---|
| 1 | `Slider` speaks raw fractions ("0.15") | 4.1.2, 1.3.1 | High | Add `valueText` to `SliderProps`; this screen passes unit strings from `05-copy.md` |
| 2 | Placement editor would be drag-only without nudges | 2.5.7 | High | Nudge buttons, keyboard arrows, reset; caption names them |
| 3 | Preview label is long (about 90 characters) | 1.1.1 | Low | Keep one element; order the facts hand → size → opacity → mode so the first words carry the most |
| 4 | Segment group visible label ("Mode") is ambiguous without its section | 2.4.6 | Medium | `aria-label` carries "Stick mode"; web `<legend>` carries the section |
| 5 | Clamp notice could be missed by a screen-reader user who lands below it | 4.1.3 | Low | Announce `g03.clamped` politely once on mount when present |
